# Contributing

Thanks for helping improve this repository.

## Making changes

1. Fork the repository or create a new branch from the latest default branch.
2. Make a focused change that addresses one issue or improvement.
3. Keep edits consistent with the existing file style and structure.
4. Review your changes before opening a pull request.

## Pull requests

When opening a pull request:

- Use a clear title that summarizes the change.
- Describe what changed and why.
- Link related issues when applicable.
- Mention any testing or checks you performed.
- Keep the pull request small enough to review easily.

## Review process

After opening a pull request, respond to review comments and update your branch as needed. Once the change is approved and checks pass, it can be merged by a maintainer.
